# 手機橫向資訊欄與方向鍵驗證

日期：2026-10-30

## 修改

- 棋盤上方保留獨立資訊列，資訊欄及語言／設定按鈕不覆蓋棋盤。
- 移動區改為四個透明方向按鈕，按住時亮起、放開時熄滅；同步更新 aria-pressed。
- 各方向與炸彈分別記錄手指，支援多點觸控、第二方向與鍵盤操作；取消、失去捕捉、切換 App 時清除輸入。
- 保留原本左右手、尺寸與透明度設定，更新繁中／簡中／英文說明。

## 驗證結果

- `npm test`：完整通過，涵蓋規則、AI 完整對局、教學、語系、版面、房間生命週期、伺服器及線上流程。
- `node scripts/touch-check.js`：23 項瀏覽器檢查通過，包括資訊列與棋盤間距、四鍵、亮起狀態、多指、同時放炸彈、第二方向、pointercancel／lostpointercapture、背景清除及鍵盤放開。
- `node tests/layout.js`：37 項通過。
- `node scripts/layout-matrix.js 'iPhone SE'`：667×375 的 2／4／8 人版面皆通過。回歸條件改為資訊列必須在棋盤上方並留至少 4px，保留原有資訊元件重疊與裁切檢查。
- Chrome / Playwright：繁中、英文 × 667×375、844×390、390×844、768×1024、1024×768、1440×900 × 2／8 人共 24 組遊戲版面通過；手機直向維持既有轉向提示。
- 同一瀏覽器走查首頁、玩法、單機設定、教學列表，以及角色、大廳、全域設定；確認沒有整頁水平溢出。遊戲中四鍵、多指、同時放炸彈、鍵盤輸入與背景重置通過。
- 使用正常規則與 AI 輸入加速模擬完整單機局（119 秒），結算後實際操作再玩一局、暫停／繼續，確認沒有殘留方向。瀏覽器未出現未處理的 JavaScript 錯誤。
- 實際遊戲截圖位於忽略的 `shots/mobile-controls/`，包含各尺寸與方向鍵亮起畫面。
- `node --check public/js/game.js`、`node --check public/js/locales.js`、`git diff --check` 通過；本專案為原生靜態前端，沒有獨立 build 或 formatter 指令。

## 最後確認

依 loop-engineering 執行一輪有界重查：以資訊列與棋盤實際邊界、輸入狀態清除與完整局／再開局作為完成條件。更新原本要求資訊列位於外牆的舊測試，改驗證新的獨立資訊列；未發現需追加修復的玩法問題。

本次為桌面 Chrome 裝置尺寸與 Pointer Events 模擬，尚未使用實體手機驗證觸控與瀏覽器安全區；線上房間／觀戰及重連由既有整合測試覆蓋，未逐一以瀏覽器人工操作。沒有執行正式環境部署或完整 42 組舊版面矩陣。
